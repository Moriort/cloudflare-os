# Oretron Dashboard

Panel de control para gestionar proyectos, leads y métricas de Oretron.

## Funcionalidades

- Vista general de proyectos activos
- Lista de leads recientes con estado
- Métricas clave (proyectos, leads, documentos, agentes)
- Diseño dark industrial seguindo tokens de Oretron

## Conexiones

Este blueprint requiere una conexión a Supabase para datos en tiempo real.

## Uso

1. Crear un nuevo gadget desde este blueprint
2. Conectar con la base de datos de Supabase
3. El dashboard muestra datos mock (reemplazar con queries reales)
